# Ancient Faith, Latter-day Questions

A static website starter for the podcast.

## Files
- `index.html` — homepage
- `episodes.html` — episode archive
- `about.html` — about page
- `resources.html` — primary-source library
- `reading.html` — further reading
- `episodes/restoration-of-all-things.html` — sample episode page
- `css/style.css` — site styling
- `images/logo.png` — podcast logo

## GitHub Pages
Upload the contents of this folder to a GitHub repository. In the repository settings, enable GitHub Pages using the main branch and `/root`.

The site is intentionally static. Podcast audio should be hosted by a dedicated podcast host; replace the player placeholder with that host's embed/RSS player once the podcast is set up.
